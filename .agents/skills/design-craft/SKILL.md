# Design Craft Doctrine (Anti-AI-Slop & High-Fidelity UI)

This skill governs all frontend, website, web app, mobile companion, and notification designs.

---

## 1. The Anti-AI-Slop Banlist (Never Do These)

| AI UI Trope | Why It's Terrible | The High-Craft Replacement |
| :--- | :--- | :--- |
| **Purple/Indigo gradients or blue color casts** | Lazy AI cliché; screams "generated by ChatGPT". | **Official Antigravity IDE neutral dark palette**: Neutral charcoal dark mode (`#181818` canvas, `#1f1f1f` cards, `#262626` inputs, `#2d2d2d` - `#333333` active selections) with signature Antigravity Blue (`#0078d4` / `#007acc`), Git Additions green (`#4ade80`), and Git Modified amber (`#f59e0b`). |
| **Giant pill buttons with diffuse blur shadows** | Bulky, wastes vertical space, childish toy aesthetic. | **Precise tactile buttons**: `border-radius: 6px-8px`, 1px crisp borders (`border: 1px solid rgba(255,255,255,0.08)`), subtle inner highlight, `active:scale-[0.98]`. |
| **Unstyled monospace JSON dumps** | Incomprehensible on mobile; overflows screen. | **Structured parameter chips**: Key-value rows, collapsible badges, syntax-highlighted code blocks, copy buttons. |
| **Floating cards with giant margins** | Low information density; forces endless scrolling. | **High-density Linear/Antigravity layouts**: 10px-14px padding, 1px hairline dividers, crisp borders, compact typography. |
| **Generic emojis as icons** | Looks like a prototype from 2018. | **Clean SVG iconography**: Lucide or Heroicons with consistent 1.5px-2px stroke weights. |

## 2. Core Aesthetic Pillars (Developer & Mobile Tooling)

### A. Surface Architecture & Layering
Instead of random background colors or blue-tinted slates, use the Antigravity IDE elevation system:
1. **Base Layer (Canvas / IDE Window):** Neutral charcoal dark (`#181818`)
2. **Elevated Surfaces (Cards / Sheets / Modals):** `#1f1f1f` - `#212121` with `border: 1px solid rgba(255, 255, 255, 0.08)`
3. **Input & Code Blocks:** `#262626` - `#282828`
4. **Interactive Hover / Active Selection:** `#2d2d2d` - `#333333` (e.g. active radio items)
5. **Primary Action Accent:** Antigravity blue (`#0078d4` / `#007acc`)

### B. Typographic Hierarchy
- **Font Stack:** Clean modern sans-serif (`Inter`, `Plus Jakarta Sans`, system sans) paired with a monospace font (`Geist Mono`, `JetBrains Mono`, `Fira Code`) for commands and data.
- **Micro-copy & Badges:** `font-size: 10px - 11px`, `font-weight: 600`, `letter-spacing: 0.04em`, uppercase with small pill padding (`px-2 py-0.5`).
- **Body & Captions:** High contrast for primary text (`#cccccc` / `#ffffff`), muted for secondary (`#9e9e9e`), dim for tertiary (`#858585`).

### C. Motion & Tactility
- All interactive actions must have instant physical feedback:
  - Button press: `transform: scale(0.98); transition: transform 0.1s ease;`
  - Hover / Focus: Border glow illumination (`border-color: rgba(255,255,255,0.2)`).
  - Status transitions: Subtle 200ms ease.

---

## 3. UI States Mandate
Every view or component must explicitly design all five lifecycle states:
1. **First Run / Empty:** Clear instruction on how to start or what to do next.
2. **Loading / Streaming:** Skeleton loader, subtle breathing pulse, or streaming token cursor.
3. **Active / Busy:** Clear spinner or activity badge.
4. **Action Required (Permission Gate):** Prominent, high-contrast, attention-grabbing card with high-priority action buttons.
5. **Error / Disconnected:** Actionable recovery button (e.g., "Reconnect", "Check IP").
